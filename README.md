**PySprint** is a daily coding initiative dedicated to sharpening algorithmic thinking, mastering core Python internals, and building consistent problem-solving momentum—one sprint at a time.

---

## 🎯 How Each Sprint Works

Every daily sprint consists of **three progressive challenges** designed to stretch logic from foundational syntax to optimal time-space complexity:

| Tier | Focus Areas | Core Concepts |
| :--- | :--- | :--- |
| 🟢 **Basic** | Syntax & Fundamentals | Strings, loops, conditionals, list comprehensions, basic I/O |
| 🟡 **Intermediate** | Data Structures & Edge Cases | Hash maps (`dict`), sets, two-pointers, string manipulation |
| 🔴 **Advanced** | Optimization & Algorithms | $O(n)$ time complexity, sliding window, recursion, dynamic patterns |

### 📝 Challenge Format
Each entry is structured around **guided problem-solving** rather than rote memorization:
1. **The Problem:** Clear constraints, requirements, and edge cases.
2. **Logic Prompt:** Step-by-step hints to guide intuition without giving away the answer.
3. **Test Cases:** Sample inputs and expected outputs for verification.
4. **My Implementation:** Clean, readable, and Pythonic code.

## 🛠️ Technologies & Tools Used

* **Core Language:** Python 3.x
* **Standard Libraries:** `collections`, `itertools`, `math`, `heapq`, `functools`, `typing`
* **Code Quality & Standards:** PEP 8 formatting guidelines, static type annotations, and Big-O complexity analysis
* **Development & Version Control:** VS Code / PyCharm, Git, and GitHub for streak tracking

---

## 💡 Coding Principles Followed

* **Clarity Over Cleverness:** Writing self-documenting variable names and modular, reusable functions.
* **Complexity Awareness:** Analyzing time $O(T)$ and space $O(S)$ trade-offs before settling on a final solution.
* **Edge-Case First:** Testing against empty inputs, duplicates, negative numbers, and large datasets.
* **Zero External Bloat:** Solving problems using pure Python and its standard library to strengthen core fundamentals.
